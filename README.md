# 🌼 bloomingcollects.info

A playful garden of random projects. Plain HTML/CSS/JS with no build step, so it deploys to Cloudflare Pages as-is.

## Add a project
1. Make a folder: `projects/<name>/index.html`
2. Add an entry to `projects.js`
3. Commit and push. Cloudflare Pages redeploys automatically.

Statuses: `seedling` 🌱 · `sprouting` 🌿 · `bloomed` 🌸 · `wilted` 🥀

## Deploy (Cloudflare Pages)
- Framework preset: **None**
- Build command: *(empty)*
- Build output directory: `/`
